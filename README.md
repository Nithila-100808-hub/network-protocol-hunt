## 📋 Project Overview

**Network Protocol Hunt** is an interactive web application designed as a college mini project for cybersecurity students. It provides a visually appealing, dark-themed dashboard to explore common network protocols, simulate packet analysis, and compare security protocols like HTTP vs HTTPS.

The project is built entirely with **vanilla HTML, CSS, and JavaScript** — no external frameworks or libraries are used, making it lightweight, fast, and easy to understand for beginners.
